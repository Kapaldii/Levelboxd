## 📖 Sobre o projeto

Game Backlog é um projeto pessoal de desenvolvimento de software que tem como objetivo criar uma plataforma de descoberta, avaliação e gerenciamento e reviews de jogos eletrônicos.

Inspirado em plataformas como IMDb e Letterboxd, o sistema pretende reunir informações sobre videogames e permitir que jogadores organizem suas coleções e acompanhem seu progresso.

O projeto começou como uma aplicação de terminal em Java e está evoluindo gradualmente para uma aplicação web.

## 🚧 Status do projeto

**Em desenvolvimento — fase inicial.**

### Funcionalidades já implementadas

- Cadastro de jogos
- Listagem de jogos cadastrados
- Busca pelo nome
- Alteração de status basica
- Remoção de jogos

### Funcionalidades planejadas

- Interface web responsiva
- Catálogo com imagens e informações dos jogos
- Páginas de detalhes dos jogos
- Avaliações e notas
- Coleções personalizadas
- Perfil do jogador
- Persistência em banco de dados
- Noticias e recomendações

## 🛠️ Tecnologias

**Utilizadas atualmente:** Java, Maven, JUnit 5 e Git.

**Planejadas:** HTML, CSS, JavaScript, Spring Boot e banco de dados.

## 🎯 Objetivo de aprendizado

Aplicar conceitos de orientação a objetos, testes automatizados, desenvolvimento web, APIs REST, persistência de dados e boas práticas de engenharia de software.
